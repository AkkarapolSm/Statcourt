# Statcourt — Visual brand direction

วันที่: 3 ตุลาคม 2026 · ปรับปรุงล่าสุด: 4 ตุลาคม 2026 (เพิ่มผลวิเคราะห์ ค่า contrast และกติกาการใช้งาน)  
สถานะ: ข้อเสนอทิศทางแบรนด์สำหรับนำไปออกแบบเว็บ  
ทิศทางแนะนำ: **Courtside Editorial**

## จุดยืนของแบรนด์

**Statcourt คือพื้นที่ที่ผลงานในสนามกลายเป็นข้อมูลที่เข้าใจได้ และเป็นโอกาสต่อไปของนักบาสไทย**

แนวทางนี้อิงพันธกิจใน DESIGN.md และหน้าที่มีอยู่ในโปรเจกต์ ได้แก่ เกมสด สถิติ โปรไฟล์นักกีฬา วิดีโอ แมวมอง โอกาสการศึกษา และเครื่องมือจัดการแข่งขัน

บุคลิกหลัก: น่าเชื่อถือ มีพลัง เข้าใจง่าย และเห็นคุณค่าของนักกีฬาทุกระดับ

ข้อความแบรนด์ที่เสนอ: **“ทุกเกม มีความหมาย”**  
ข้อความรอง: “ติดตามเกม ดูสถิติ และค้นพบโอกาสต่อไปของนักบาสไทย”  
English campaign line: “Every game. More possibility.”

### Courtside Editorial — จุดแข็งและสิ่งที่ต้องแก้

**จุดแข็ง:** ลำดับข้อมูลชัด (คะแนน → ทีม → ควอเตอร์) แดงถูกใช้เป็นจุดกระทำและ LIVE ตามที่ตั้งใจ พื้นสว่างสลับกรมท่าช่วยแยกโหมดอ่านกับโหมดเกมสด

| ประเด็นที่พบ | ผลกระทบ | การแก้ในเอกสารนี้ |
|---|---|---|
| Crimson `#AF101A` บน Court Ink มี contrast **2.38:1** | ตัวอักษร ไอคอน หรือจุด LIVE สีแดงบนพื้นกรมท่าอ่านไม่ผ่านเกณฑ์ | เพิ่ม **Signal Red** `#FF7A7A` (6.80:1) สำหรับพื้นมืด |
| Line `#DFE2EB` บน Ice มีเพียง **1.23:1** | เหมาะเป็นเส้นแบ่งตาราง แต่ช่องกรอกและตัวควบคุมมองไม่เห็นขอบ | เพิ่ม **Border Strong** `#7F8A9E` (3.31:1) สำหรับตัวควบคุม |
| แถบล่างของ hero ใช้ตัวเลขใหญ่เท่ากันกับค่าที่ความหมายต่างกัน (`68 : 61`, `U18`, `PPG`) | ผู้ใช้ใหม่ไม่รู้ว่า `PPG` คืออะไร และตัวเลขทุกตัวดูสำคัญเท่ากัน | คะแนนเกมใช้ขนาดเต็ม ส่วนรุ่นอายุและตัวย่อสถิติลดขนาดและมีคำอธิบายภาษาไทย (ดูหัวข้อตัวอักษร) |
| หัวข้อ hero ภาษาอังกฤษใหญ่กว่าภาษาไทยมาก | ผู้ใช้ไทยอ่านข้อความขายหลักจากบรรทัดที่เล็กกว่า | กำหนดอัตราส่วนขั้นต่ำและให้หน้าใช้งานจริงใช้หัวข้อไทยเป็น `h1` |
| `.TH` ใน wordmark เล็กและลอยเหนือเส้นฐาน | ที่ขนาดเล็กอ่านเป็นจุดและเลือนหาย | กำหนดขนาดต่ำสุดและรูปแบบย่อ (ดูหัวข้อ Wordmark) |
| Medal มีในชุดสีแต่ไม่ปรากฏบน board | ยังไม่ได้พิสูจน์การใช้สีทองกับพื้นสว่างและพื้นมืด | ระบุคู่สีที่อนุญาตและห้ามใช้ขาวบนทอง (1.70:1) |

### Performance Lab — เก็บเป็นโหมด ไม่ใช่แบรนด์แยก

- ในภาพ board แถวผู้เล่นของตาราง `PTS / REB / AST` จางจนแทบอ่านไม่ได้ ทั้งที่ตารางผู้เล่นเป็นหัวใจของโหมดนี้ ต้องแก้ก่อนนำไปใช้เป็นต้นแบบ
- เขียวมะนาวทำงานดีบนกราไฟต์ (13.77:1) แต่ถ้าใช้เป็นสีหลัก เว็บจะมีสองแบรนด์ ซ้ำกับแดงในหน้าเกมสด
- **ข้อเสนอ:** หน้าวิเคราะห์ใช้พื้นกรมท่า Court Ink และตัวเลขสีขาว ใช้ Signal Red เป็นจุดเน้น ส่วนเขียวมะนาวเก็บไว้เป็นสีหนึ่งใน data visualization palette ไม่เป็นสีแบรนด์

### Next Generation — ยืมเรื่องเล่า ไม่ยืมสี

- Nav ที่เลือกอยู่เป็นสีน้ำเงิน แต่ปุ่มหลักเป็นส้มอิฐ ทำให้มีสีเน้นสองสีแข่งกัน และส้มอิฐ `#B5401E` ใกล้กับ Pending `#B45309` มาก (contrast ระหว่างกัน 1.13:1) ผู้ใช้จะสับสนระหว่างปุ่มกับสถานะรอตรวจสอบ
- กรอบหมายเลขเสื้อสีน้ำเงินเต็มทำให้หน้าโปรไฟล์ไม่เหมือนเว็บเดียวกันกับหน้าอื่น
- **ข้อเสนอ:** กรอบ player spotlight ใช้ Court Ink พร้อมเส้นสนามบางและ Crimson เป็นจุดเน้น สีของทีม (เช่น BCC, DS) แสดงเป็นชิปสีเล็กข้างชื่อทีมเท่านั้น และ Canvas ครีมไม่ใช้เป็นพื้นหน้า

สัดส่วนเริ่มต้นสำหรับหน้าอ่านข้อมูล: พื้นสว่าง 60% กรมท่าและตัวอักษร 30% สีแบรนด์และสีสถานะ 10% สัดส่วนนี้เป็นแนวทางเชิงภาพ ไม่ใช่สูตรสำหรับทุกหน้า หน้าเกมสดสามารถมีพื้นที่กรมท่ามากขึ้นตามบริบท

สถานะต้องมีข้อความหรือสัญลักษณ์ร่วมกับสี เช่น “รับรองผลแล้ว” “รอตรวจสอบ” “กำลังแข่งขัน” สีแดงของแบรนด์และข้อผิดพลาดแยกความหมายด้วยคำกำกับและรูปแบบข้อความ

## ตัวอักษร

ลดชุดฟอนต์เหลือสองตระกูลที่มีใช้อยู่ในโปรเจกต์:

- **Barlow Condensed:** wordmark ภาษาอังกฤษ หัวข้อแคมเปญภาษาอังกฤษ คะแนน และตัวเลขเด่น
- **Noto Sans Thai:** หัวข้อภาษาไทย เนื้อหา ปุ่ม เมนู และคำอธิบายสถิติ

| บทบาท | Desktop | Mobile | น้ำหนัก / การจัดวาง |
|---|---|---|---|
| English campaign | 56–72 px | 40–48 px | 600–700; บรรทัดกระชับ |
| Thai hero heading | 36–44 px | 28–32 px | 600–700; line height 1.35–1.45 |
| Section heading | 24–28 px | 22–24 px | 600 |
| Body และ UI | 15–16 px | 15–16 px | 400–500; line height 1.6–1.8 |
| Secondary label | 12–13 px | 12–13 px | 400–500 |
| Main score | 56–72 px | 48–60 px | 600; tabular numerals |
| Table numbers | 14–16 px | 14–16 px | tabular numerals; ชิดขวา |

ตัวอย่างขนาดใน brand board เป็นขนาดสำหรับ preview ส่วนตารางนี้เป็นขนาดเป้าหมายของเว็บจริง หัวข้อไทยใช้ Noto Sans Thai โดยตรงเพื่อคุมรูปทรงและการตัดบรรทัด ตัวเลขตารางต้องรักษาความกว้างคงที่เมื่อคะแนนเปลี่ยน

กติกาเพิ่มเติมสำหรับข้อความไทย:

- **ห้ามใส่ letter-spacing กับข้อความไทย** และห้ามใช้ `uppercase` กับข้อความไทย สระและวรรณยุกต์จะแยกจากพยัญชนะ ใช้ tracking กว้างและตัวพิมพ์ใหญ่เฉพาะป้ายภาษาอังกฤษ เช่น `MATCH CENTER`
- Barlow Condensed ไม่มีอักษรไทย (เป็น Latin เท่านั้น) จึงห้ามกำหนดเป็นฟอนต์ของเนื้อหาหรือส่วนควบคุมที่มีภาษาไทย ให้ใช้ Noto Sans Thai
- ข้อความไทยบนพื้นมืดเพิ่มน้ำหนักขึ้นหนึ่งระดับหรือ line height อีกประมาณ 0.05 เพื่อไม่ให้วรรณยุกต์ติดกัน
- หัวข้อภาษาไทยในหน้าใช้งานจริงเป็น `h1` ส่วนข้อความอังกฤษเป็นภาพลักษณ์ประกอบ เมื่อวางคู่กัน บรรทัดไทยควรมีขนาดอย่างน้อย 60% ของบรรทัดอังกฤษ
- ตัวย่อสถิติ (PPG, REB, AST, eFG%) ใช้ได้เมื่อมีคำอธิบายไทยใกล้กัน เช่น “แต้มเฉลี่ยต่อเกม (PPG)” อย่างน้อยหนึ่งครั้งต่อหน้า หรือแสดงผ่าน tooltip ที่เข้าถึงด้วยคีย์บอร์ดได้
- ค่าที่ไม่ใช่คะแนนเกม เช่น รุ่นอายุ (`U18`) และตัวย่อสถิติ ใช้ขนาดตัวเลขรอง (24–32 px) เพื่อให้คะแนนเกมเป็นตัวเลขที่ใหญ่ที่สุดในหน้า
- ตรวจว่าฟอนต์ที่ส่งจริงรองรับ tabular numerals (`font-variant-numeric: tabular-nums`) ก่อนใช้กับคะแนนสด

## Wordmark และองค์ประกอบที่จำได้

แนวคิด wordmark: **STATCOURT.TH** ตั้งด้วย Barlow Condensed น้ำหนัก 700 พร้อมแท่งคะแนนสามแท่งที่ไล่ความสูง ใช้เป็นการศึกษาแนวทางโลโก้ก่อนสร้างไฟล์เวกเตอร์ฉบับใช้งานจริง

องค์ประกอบหลัก:

1. เส้นสนาม: เส้นบาง 1 px หรือ crop วงกลมกลางสนาม/เขตยิง เพื่อผูกแบรนด์กับบาสเกตบอล
2. ลำดับคะแนน: คะแนนใหญ่ที่สุด ตามด้วยทีม ควอเตอร์ เวลา และคำอธิบายสถานะ
3. Editorial grid: พื้นที่เกมเด่นหนึ่งจุด ตามด้วยโปรแกรม ผลแข่ง และผู้นำสถิติ
4. Section labels: หัวข้อสั้น เช่น MATCH CENTER, STAT LEADERS, NEXT CHAPTER ใช้เฉพาะตำแหน่งที่ช่วยสแกนหน้า
5. Jersey number: หมายเลขเสื้อเป็นตัวช่วยเล่าเรื่องในโปรไฟล์และกราฟิกสำหรับแชร์

### กติกา Wordmark (ใช้ตอนสร้างไฟล์เวกเตอร์)

| หัวข้อ | กติกาเริ่มต้น |
|---|---|
| รูปแบบหลัก | แท่งคะแนนสามแท่ง + `STATCOURT` + `.TH` บนเส้นฐานเดียวกัน |
| ความกว้างต่ำสุด | รูปแบบเต็มไม่ต่ำกว่า 120 px ที่ต่ำกว่านั้นให้ใช้แท่งคะแนนอย่างเดียว หรือ `STATCOURT` ไม่มี `.TH` |
| `.TH` | ความสูงไม่ต่ำกว่า 60% ของความสูงตัวอักษรหลัก ชิดเส้นฐาน ไม่ลอยเหนือเส้นฐาน |
| พื้นที่ปลอดภัย | เว้นรอบโลโก้ไม่น้อยกว่าความกว้างของแท่งคะแนนหนึ่งแท่ง |
| สี | บนพื้นสว่าง: แท่ง Crimson ตัวอักษร Court Ink บนพื้นมืด: แท่ง Signal Red ตัวอักษรขาว ไม่ใช้ Crimson `#AF101A` บนพื้นมืด |
| Favicon / avatar | แท่งคะแนนสามแท่งอย่างเดียว บนพื้นสี่เหลี่ยมมุมมน |
| ห้าม | ยืดหรือบีบสัดส่วน เพิ่มเงา เปลี่ยนความสูงแท่ง ใส่เส้นสนามทับตัวอักษร หรือใช้สีทองกับตัวโลโก้ |

## ภาพถ่ายและภาพเคลื่อนไหว

ภาพหลักใช้เกมและนักกีฬาจริงในบริบทไทย: จังหวะส่งบอล การป้องกัน การรวมทีม และบรรยากาศโรงเรียนหรือสนามชุมชน ใช้มุมที่เห็นความพยายามและทีมเวิร์ก แสงและสีผิวเป็นธรรมชาติ

ครอปภาพให้มีจุดสนใจหลักหนึ่งจุดและพื้นที่ว่างสำหรับข้อความ หากวางข้อความทับภาพ ใช้แถบกรมท่าหรือ overlay ที่อ่านได้ชัด ภาพบุคคลและหมายเลขเสื้อเป็นแกนของ player spotlight

หน้าอ่านสถิติใช้พื้นเรียบ กราฟกับตารางเป็นองค์ประกอบหลัก เอฟเฟกต์เคลื่อนไหวใช้เพื่ออธิบายการเปลี่ยนคะแนนหรือสถานะ ระยะเวลาเริ่มต้น 150–200 ms และรองรับ reduced motion

## รูปแบบ UI

- พื้นอ่านข้อมูลสว่าง ส่วนเกมสด/วิดีโอใช้กรมท่า
- การ์ดมุม 4–8 px ปุ่มมุม 4–6 px เงาบางเฉพาะพื้นที่ที่ต้องแยกชั้น
- กริดระยะห่าง 8 px; desktop gutter 24–32 px; mobile gutter 16–20 px
- ปุ่มหลักสีแดงมีหนึ่งเป้าหมายเด่นต่อส่วน ปุ่มรองใช้พื้นเรียบหรือเส้นขอบ
- Scoreboard แสดงทีม คะแนน สถานะ ควอเตอร์และเวลาที่มองเห็นได้พร้อมกัน
- ตารางมีเส้นแนวนอนบาง ชื่อตัวอักษรชิดซ้าย ตัวเลขชิดขวา ไม่ใส่สีคนละสีให้ทุกแถว
- Tabs ใช้ selected state ชัดเจนและเข้าถึงได้ด้วยคีย์บอร์ด
- พื้นที่กดบนมือถือประมาณ 44 px ขึ้นไป รักษาขนาดข้อความที่อ่านได้
- Loading, empty, error และ offline ใช้ภาษาเรียบง่าย พร้อมการกระทำถัดไปที่เหมาะกับสถานะ
- ช่องกรอกและปุ่มรองต้องมีขอบ Border Strong (≥ 3:1) ไม่ใช้ Line `#DFE2EB` เป็นขอบตัวควบคุม
- Focus ring: เส้นขอบ 2 px สี Court Ink บนพื้นสว่าง และสีขาวบนพื้นมืด มี offset 2 px และเห็นได้ทุกครั้งที่ใช้คีย์บอร์ด
- สถานะ LIVE มีจุดเคลื่อนไหวพร้อมคำว่า “กำลังแข่งขัน” หรือ `LIVE` ไม่ใช้จุดสีเพียงอย่างเดียว และหยุดเคลื่อนไหวเมื่อเปิด reduced motion
- ชิปสีทีม (BCC, DS ฯลฯ) ใช้เป็นจุดสีเล็กข้างชื่อทีมเท่านั้น ห้ามใช้เป็นพื้นของส่วนหน้าหรือสีปุ่ม
- กรอบ player spotlight ใช้ Court Ink เส้นสนามบาง และหมายเลขเสื้อสีขาว ไม่ใช้สีน้ำเงินหรือส้มอิฐที่อยู่นอกชุดสี

## น้ำเสียงและตัวอย่างข้อความ

ใช้ประโยคสั้น เป็นภาษาไทยธรรมชาติ และให้ข้อมูลก่อนคำขาย ใช้ภาษาอังกฤษเฉพาะชื่อสถิติหรือป้ายสั้นที่ผู้ใช้คุ้นเคย

| บริบท | ข้อความที่เสนอ |
|---|---|
| Hero | “ทุกเกม มีความหมาย” |
| Hero supporting text | “ติดตามเกม ดูสถิติ และค้นพบโอกาสต่อไปของนักบาสไทย” |
| Primary action | “ดูเกมและสถิติ” |
| Athlete profile | “ให้ผลงาน พาคุณไปต่อ” |
| Stat verification | “รับรองผลแล้ว” |
| Pending result | “รอตรวจสอบผลการแข่งขัน” |
| Empty state | “ยังไม่มีการแข่งขันในวันที่เลือก” |
| Offline console | “ออฟไลน์อยู่ — บันทึกข้อมูลไว้บนอุปกรณ์แล้ว” ใช้เมื่อระบบบันทึกจริงสำเร็จ |

คำว่า “รับรอง” ใช้ตามสถานะจริงของข้อมูล ส่วนการกล่าวถึง FIBA สมาคม หรือพันธมิตรแสดงเฉพาะความสัมพันธ์และขอบเขตที่ยืนยันได้

## แผนการนำไปใช้

1. ทำ color และ type tokens ให้เป็นชุดเดียว ปัจจุบัน DESIGN.md, globals.css และบาง component ระบุค่าสีและตัวอักษรต่างกัน (รายการความขัดแย้งอยู่ในตาราง “การย้าย tokens” ด้านล่าง)
